Rust: Traits vs Methods

Trait: A shared behavior defined by method signatures. Structs or enums implement traits to gain this behavior.

Method: A function defined on a specific type (via impl). Methods can exist independently of traits.

1️⃣ Combined Example (Trait + Method)


// Trait
trait Greet {
    fn say_hello(&self);
}

// Struct
struct Person {
    name: String,
}

// Trait implementation
impl Greet for Person {
    fn say_hello(&self) {
        println!("Hello, my name is {}!", self.name);
    }
}

// Regular methods
impl Person {
    fn new(name: &str) -> Self {
        Person {
            name: name.to_string()
        }
    }

    fn say_goodbye(&self) {
        println!("Goodbye from {}!", self.name);
    }
}

fn main() {
    let person = Person::new("Alice");
    person.say_hello();     // Trait method
    person.say_goodbye();   // Regular method
}

2️⃣ Trait-Only Example: Animal Sounds


trait Animal {
    fn sound(&self) -> &str;
}

struct Dog;
struct Cat;

impl Animal for Dog {
    fn sound(&self) -> &str {
        "Woof!"
    }
}

impl Animal for Cat {
    fn sound(&self) -> &str {
        "Meow!"
    }
}

fn main() {
    let dog = Dog;
    let cat = Cat;

    println!("Dog says: {}", dog.sound());
    println!("Cat says: {}", cat.sound());
}

3️⃣ Trait-Only Example: Area Calculation


trait Area {
    fn area(&self) -> f64;
}

struct Circle {
    radius: f64,
}

struct Rectangle {
    width: f64,
    height: f64,
}

impl Area for Circle {
    fn area(&self) -> f64 {
        3.1415 * self.radius * self.radius
    }
}

impl Area for Rectangle {
    fn area(&self) -> f64 {
        self.width * self.height
    }
}

fn main() {
    let c = Circle { radius: 3.0 };
    let r = Rectangle { width: 4.0, height: 5.0 };

    println!("Circle area: {}", c.area());
    println!("Rectangle area: {}", r.area());
}

4️⃣ Method-Only Example: Counter Struct


struct Counter {
    value: i32,
}

impl Counter {
    fn new() -> Self {
        Counter { value: 0 }
    }

    fn increment(&mut self) {
        self.value += 1;
    }

    fn get(&self) -> i32 {
        self.value
    }
}

fn main() {
    let mut counter = Counter::new();
    counter.increment();
    counter.increment();
    println!("Counter value: {}", counter.get());
}

5️⃣ Method-Only Example: Temperature Conversion


struct Temperature {
    celsius: f64,
}

impl Temperature {
    fn from_celsius(c: f64) -> Self {
        Temperature { celsius: c }
    }

    fn to_fahrenheit(&self) -> f64 {
        (self.celsius * 9.0 / 5.0) + 32.0
    }
}

fn main() {
    let temp = Temperature::from_celsius(25.0);
    println!("Temp in °F: {}", temp.to_fahrenheit());
}

Key Learning:

  • Traits are best when you want to define behavior that multiple types can implement.
  • Methods are useful for type-specific behavior or utility functions.
