Comprehensive Rust: Traits, Methods, and Structs

Structs in Rust

A struct is a custom data type that packages together multiple related values.

struct Rectangle {
    width: u32,
    height: u32,
    name: String,
}

Methods in Rust

Methods are functions associated with a type, defined in impl blocks.

Three Types of Methods:

impl Rectangle {
    // 1. Associated function (no self parameter)
    fn new(width: u32, height: u32, name: &str) -> Self {
        Self {
            width,
            height,
            name: String::from(name),
        }
    }
    
    // 2. Immutable method (&self)
    fn area(&self) -> u32 {
        self.width * self.height
    }
    
    // 3. Mutable method (&mut self)
    fn resize(&mut self, new_width: u32, new_height: u32) {
        self.width = new_width;
        self.height = new_height;
    }
    
    // Method consuming self (self)
    fn consume(self) -> String {
        format!("Consumed rectangle: {}", self.name)
    }
}

Method Types Explained:

  • &self: Borrows the instance immutably (read-only)
  • &mut self: Borrows the instance mutably (can modify)
  • self: Takes ownership of the instance (consumes it)

Traits in Rust

Traits define shared behavior that can be implemented by multiple types.

Basic Trait with Default Implementation

trait Summary {
    // Required method
    fn summarize(&self) -> String;
    
    // Method with default implementation
    fn brief(&self) -> String {
        String::from("(Read more...)")
    }
}

Trait with &mut self Method

trait Resizable {
    fn scale(&mut self, factor: f64);
    fn double_size(&mut self) {
        self.scale(2.0);
    }
}

Trait with Associated Type

trait Shape {
    type AreaType;
    
    fn area(&self) -> Self::AreaType;
    fn description(&self) -> String;
}

Trait Implementations

Implementing Summary for Rectangle

impl Summary for Rectangle {
    fn summarize(&self) -> String {
        format!("Rectangle '{}' ({}x{}), area: {}", 
            self.name, self.width, self.height, self.area())
    }
}

Implementing Resizable for Rectangle

impl Resizable for Rectangle {
    fn scale(&mut self, factor: f64) {
        self.width = (self.width as f64 * factor) as u32;
        self.height = (self.height as f64 * factor) as u32;
    }
}

Implementing Shape for Rectangle

impl Shape for Rectangle {
    type AreaType = u32;
    
    fn area(&self) -> Self::AreaType {
        self.width * self.height
    }
    
    fn description(&self) -> String {
        self.summarize()
    }
}

Complete Example with Usage

fn main() {
    // Create a mutable Rectangle
    let mut rect = Rectangle::new(30, 50, "My Rectangle");
    
    // Call immutable method
    println!("Initial area: {}", rect.area());
    
    // Call trait method (Summary)
    println!("{}", rect.summarize());
    
    // Call mutable method
    rect.resize(40, 60);
    println!("After resize: {}", rect.summarize());
    
    // Call trait method with &mut self (Resizable)
    rect.scale(1.5);
    println!("After scaling: {}", rect.summarize());
    
    // Call default trait method
    println!("Brief: {}", rect.brief());
    
    // Call method that consumes self
    let message = rect.consume();
    println!("{}", message);
    
    // rect can no longer be used here as it was consumed
}

Expected Output:

Initial area: 1500
Rectangle 'My Rectangle' (30x50), area: 1500
After resize: Rectangle 'My Rectangle' (40x60), area: 2400
After scaling: Rectangle 'My Rectangle' (60x90), area: 5400
Brief: (Read more...)
Consumed rectangle: My Rectangle

Key Differences

Concept Purpose Key Features
Struct Data organization Contains fields, no behavior, can implement multiple traits
Method Type-specific behavior Defined in impl blocks, can be immutable/mutable/consuming
Trait Shared behavior Defines interface, can have default implementations, enables polymorphism

Important Notes:

  • Traits can't contain data fields (only structs/enums can)
  • Methods with &mut self require mutable instances
  • Traits must be in scope to use their methods
  • You can implement your traits for any type, including standard library types
