Rust Generics Explained

Rust generics allow you to write code that works with different types while keeping it type-safe and reusable.

  • Generic Struct: A struct that stores any type T.
  • Generic Enum: Like Option<T> or Result<T, E>, holds variable types.
  • Generic Method: A method using its own type parameter.
  • Generic Trait: A trait that works over generic types.

1️⃣ Generic Struct


struct Point {
    x: T,
    y: T,
}

fn main() {
    let int_point = Point { x: 5, y: 10 };
    let float_point = Point { x: 1.0, y: 4.5 };

    println!("Int point: ({}, {})", int_point.x, int_point.y);
    println!("Float point: ({}, {})", float_point.x, float_point.y);
}

2️⃣ Generic Enum


enum MyOption {
    Some(T),
    None,
}

fn main() {
    let some_number = MyOption::Some(42);
    let nothing: MyOption<&str> = MyOption::None;

    match some_number {
        MyOption::Some(val) => println!("Got: {}", val),
        MyOption::None => println!("Nothing there"),
    }

    match nothing {
        MyOption::Some(val) => println!("Got: {}", val),
        MyOption::None => println!("Empty!"),
    }
}

3️⃣ Generic Method


struct Container;

impl Container {
    fn display(item: T) {
        println!("Item: {:?}", item);
    }
}

fn main() {
    Container::display(123);
    Container::display("Hello, world!");
}

4️⃣ Generic Trait


trait Summary {
    fn summarize(&self) -> T;
}

struct Article {
    title: String,
    author: String,
}

impl Summary for Article {
    fn summarize(&self) -> String {
        format!("{} by {}", self.title, self.author)
    }
}

fn main() {
    let article = Article {
        title: "Rust Generics".to_string(),
        author: "Jane Doe".to_string(),
    };

    println!("Summary: {}", article.summarize());
}

Key Takeaways:

  • Use generics to reduce code duplication.
  • <T> is a placeholder for any type.
  • Traits can be bounded with constraints like T: Debug or T: Copy.
