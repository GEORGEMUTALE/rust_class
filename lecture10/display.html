Rust: Debug vs Display

Rust has two main ways of printing a type:

  • Debug — uses {:?}, typically for developer output. Add with #[derive(Debug)].
  • Display — uses {}, meant for user-friendly output. You must manually implement it.

📱 Example: Phone Number


use std::fmt;

// Default Debug formatting
#[derive(Debug)]
struct PhoneNumber {
    country_code: String,
    number: String,
}

// Custom Display formatting
impl fmt::Display for PhoneNumber {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        write!(f, "+{} {}", self.country_code, self.number)
    }
}

fn main() {
    let phone = PhoneNumber {
        country_code: "256".to_string(),
        number: "712345678".to_string(),
    };

    // Debug output (developer-facing)
    println!("Debug: {:?}", phone);

    // Display output (user-facing)
    println!("Display: {}", phone);
}

Output:

Debug: PhoneNumber { country_code: "256", number: "712345678" }
Display: +256 712345678

Why use both?

  • Debug is automatic and useful for debugging.
  • Display is manual and gives control over how your type appears to end users.
